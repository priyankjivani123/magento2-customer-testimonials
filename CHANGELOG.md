# Changelog - Magento 2 Customer Testimonials

All notable changes to this project will be documented in this file.

## [1.0.0] - 2026-11-09
### Added
- Enterprise testimonials management module with Admin UI Grid & Form.
- Declarative Schema architecture with automated data patch lifecycle.
- REST Web API endpoints (`/V1/testimonials`) with full Swagger schema.
- Symfony CLI bulk CSV importer (`bin/magento testimonials:import`).
- Automated PHPUnit tests for status options and data providers.
- Full PHP 8.1 - 8.4 support.
